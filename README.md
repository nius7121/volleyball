# 우리반 배구 리그

학생이 각자 기기로 PAPS 기반 캐릭터를 만들고, 두 팀의 감독이 전술을 짠 뒤, 선생님 화면에서 9인제 가상 경기를 보는 **한 차시용** 수업 도구입니다.

## 수업 전 준비

1. 선생님 PC에 [Node.js](https://nodejs.org) LTS를 설치합니다. 인터넷은 처음 설치할 때만 필요합니다.
2. **학교 와이파이에서 접속 시험을 합니다.** 선생님 PC에서 `수업시작.bat`을 실행한 뒤, 학생용 기기로 화면에 나온 주소를 열어 보세요.
   - Windows 방화벽 창이 뜨면 **허용**을 누릅니다.
   - 열리지 않으면 학교망이 기기 간 통신을 막고 있을 수 있습니다. 정보 담당 선생님께 문의하거나 휴대폰 핫스팟을 사용하세요.

## 수업 순서

1. `수업시작.bat`을 더블클릭하면 선생님 화면이 열립니다. 검은 창은 닫지 마세요.
2. 학생은 QR 코드나 주소로 접속해 방 코드, 번호, 이름, PIN 4자리로 입장하고 캐릭터를 만듭니다.
3. 선생님은 자동 분배로 초안을 만들고 팀을 조정한 뒤 각 팀의 감독을 정합니다. 팀마다 선수가 9명 이상 필요하며, 모자라면 NPC로 채웁니다.
4. 10분 동안 감독이 라인업, 서브 순서, 전술을 정해 확정합니다. 못 끝내면 선생님이 감독을 바꾸거나 강제 확정합니다.
5. 두 감독이 확정하면 선생님이 경기를 시작합니다. 경기는 선생님 화면에 나오고, 학생 화면에는 점수와 내 기록이 나옵니다.
6. 감독은 자기 기기에서 작전타임(세트당 2회, 1분)과 교체를 요청합니다. 분석판에서 상대 공격 경향을 보고 전술을 고칩니다. 세트 사이 휴식도 1분이며, 시간이 끝나면 그때 설정으로 자동 재개합니다.
7. 끝나면 **수업 종료**를 누르거나 검은 창을 닫습니다.

## 개인정보

- 데이터베이스, 파일, 외부 서비스에 **아무것도 저장하지 않습니다.** 학생 정보는 서버 프로그램의 메모리에만 있고 수업 종료나 서버 종료 시 사라집니다.
- 그래서 다음 차시에 이어서 쓸 수 없고, 수업 중 PC가 꺼지거나 서버 창이 닫히면 처음부터 다시 해야 합니다.
- 다른 학생에게는 코트 이름, 외형, 포지션, 배구 능력치만 보입니다. 실명, PAPS 등급, 키, 성별은 본인과 선생님만 봅니다.
- 캐릭터의 남자·여자 모습은 PAPS 기준표에 따라 처음 정해지지만 학생이 따로 바꿀 수 있습니다. 모습은 다른 학생에게도 보이고, 비공개인 성별 값과는 별개로 저장됩니다.
- 측정값을 입력해도 등급으로만 바뀌어 전송되고 측정값 자체는 서버로 가지 않습니다.
- 선생님 화면은 학생 실명을 표시합니다. PAPS와 키는 학생 이름을 눌렀을 때만 나오므로 그 전에 프로젝터를 가려 주세요. PIN은 표시되지 않고 초기화만 할 수 있습니다.
- 글꼴과 프로그램은 모두 선생님 PC에서 내려받으며 경기 중 외부로 나가는 요청은 없습니다.

## 경기 규칙

교내 규칙서가 없어 일본 9인제 실업팀의 공개 규칙 설명을 기준으로 삼았습니다. 공식 규정집 원문을 확인한 것은 아니므로, 대회 요강과 다른 부분은 알려 주시면 고칠 수 있습니다.

| 항목 | 적용 내용 |
| :--- | :--- |
| 세트 | 3세트 2선승. 정규형 21점. 수업형 11점과 단축형 15점은 수업용 자체 규칙. 듀스는 2점 차 |
| 서브 | 2회 기회. 네트에 닿으면 실패. 등록한 순서를 경기 내내 유지 |
| 터치 | 팀당 3회. 블로킹 터치도 1회로 셈. 공이 네트에 맞으면 4회까지 허용 |
| 연속 터치 | 같은 선수 연속 터치 금지. 블로킹 후와 네트 맞은 공은 예외 |
| 자리 | 전위, 중위, 후위 3열. 로테이션 없음, 후위 공격 제한 없음 |
| 코트 교대 | 세트마다 교대. 마지막 세트는 한 팀이 11점(단축형 8점, 수업형 6점)일 때 교대 |
| 교체 | 세트당 6회. 재입장은 처음 교체한 선수와만 가능 |
| 작전타임 | 세트당 2회. 실제 규칙은 30초지만 수업용으로 1분 |

참고: [덴소텐 레드피닉스 9인제 설명](https://www.denso-ten.com/jp/volleyballteam/ninevolleyball/9volleyball/), [파나소닉 블루벨즈 규칙 소개](https://panasonic.co.jp/ew/bluebells/rule/)

## 경기 엔진 검증

```bash
npm test             # 규칙, 권한, 개인정보, 경기 진행 테스트
npm run simulate     # 수천 경기를 돌려 승률과 득점 원인 측정
```

## 개발

```bash
npm run dev:server   # 서버 (포트 3000)
npm run dev          # 화면 개발 서버 (포트 5173)
```
